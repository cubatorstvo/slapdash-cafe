# Мастер-классы и масштаб — этап 2

Реализован второй этап плана: **оператор и хайлайты**.

- Во время живого мастер-класса вокруг шеф-станции собираются четыре зрителя.
- Отдельный оператор с камерой бегает между безопасными точками вокруг рабочей зоны и периодически приседает ради кадра.
- Поведение оператора является только визуальным: фильм использует четыре фиксированных читаемых ракурса — общий, рабочая поверхность, боковой и финальная подача.
- Монтаж строится только из кадров принятого исполнения. Выбранные отрезки хранят ссылки на реальные исходные кадры.
- Суммарная длина фильма равна 30% исходной записи. 45 секунд дают 13,5 секунды; 32 секунды дают 9,6 секунды.
- Видеотека показывает длительность фильма и запускает его на существующем телевизоре комнаты отдыха.
- Телевизор рендерит сохранённое исполнение в отдельном 3D-видеопотоке и переключает фиксированные ракурсы по монтажу.
- Просмотр не ставит кафе на паузу. В сети состояние фильма общее, а гостям один раз передаются только вошедшие в монтаж кадры.
- Формат сохранения v15 хранит монтажные данные. Сохранения v14 автоматически получают детерминированную нарезку при загрузке.

Группы столов, блокноты сотрудников и учебные сеансы у телевизора относятся к этапу 3.
