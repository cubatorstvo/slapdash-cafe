# Sol — продуктовая переработка кафе

Рабочая ветка: `sol/cafe-product-layout`

## Цель
Привести основную сцену кафе к состоянию продуктового проекта: убрать визуальные и физические артефакты, расширить пространство, развести станции и проходы, привести поверхности/коллизии/пропсы к аккуратной и проверяемой структуре.

## Правила работы
- Эта ветка используется для всех промежуточных сохранений работы по сцене кафе.
- Промежуточные коммиты допустимы до полного прохождения тестов.
- После значимых этапов запускать Godot 4.7.2, тесты и визуальные capture-сценарии.
- Скриншоты сохранять локально для проверки; в репозиторий добавлять только полезные для проекта эталоны/документацию.
- Перед завершением этапа обновлять этот файл.

- Загруженный пользователем Godot 4.7.2 успешно запускается локально: версия 4.7.2.stable.official.ed1daf0bf.
- Старый успешный артефакт capture с ветки prototype-cafe-layout просмотрен. Он подтверждает исходную проблему: в позднем кафе почти все станции были сгружены в плотные пересекающиеся кластеры по краям при пустом центре.
- На локальном Godot 4.7.2 сделан отдельный геометрический layout-harness новой схемы. Визуально 20 footprint-ов стоят четырьмя ровными рядами с полноценными проходами и без пересечений. Это проверка самой схемы, а не полноценный capture игры.
- Branch-only GitHub Actions workflow для запуска настоящего проекта и сохранения 5 игровых ракурсов создан. GitHub сейчас завершает jobs до назначения runner-а (runner_id=0, пустой список steps/logs) на каждом push; это инфраструктурный сбой Actions, поэтому автозапуск на каждый промежуточный commit отключён, workflow оставлен для ручного/финального запуска.
